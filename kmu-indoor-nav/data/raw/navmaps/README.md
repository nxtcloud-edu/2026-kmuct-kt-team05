# 미래관 내비게이션 지도 시안

국민대학교 공과대학 홈페이지의 미래관 원본 도면을 바탕으로 만든 지도 앱 스타일의 시각화 시안이다.

## 파일

- `미래관_1층_내비게이션맵.png`
- `미래관_2층_내비게이션맵_v2.png` — 승강기 위치 수정본, 사용 권장
- `미래관_3층_내비게이션맵.png` — 첫 시연 목적지인 338호 강조 버전
- `미래관_4층_내비게이션맵.png`
- `미래관_5층_내비게이션맵_v2.png` — 승강기 위치 수정본, 사용 권장
- `미래관_6층_내비게이션맵.png`
- `미래관_7층_내비게이션맵.png`
- `미래관_지하1층_내비게이션맵.png`

## 공통 디자인

- 연한 민트색: 실내 이동 공간
- 파란색: 엘리베이터
- 주황색: 계단
- 초록색: 출입구
- 지하 1층의 회색 영역: 주차 구역 및 차량 동선

## 사용 전 확인

이 파일들은 AI로 단순화한 디자인 시안이다. 길찾기 서비스의 운영 데이터로 바로 사용하지 않는다. 실제 문, 출입구, 계단, 엘리베이터, 벽, 호실명과 층 연결은 원본 도면 및 현장 조사로 대조해야 한다. 호실명은 원본의 작은 글자를 재해석하는 과정에서 오류가 생길 수 있으므로, 앱에는 검증된 호실 DB의 텍스트를 별도 레이어로 올린다.

공식 도면 페이지: https://engineering.kookmin.ac.kr/engineering/etc/engineering-floor-guide.do

웹페이지에서 `지하 2층-①`, `지하 2층-②`로 보이는 두 원본은 도면 내부에 각각 `지상 1층`, `지상 2층`이라고 표기되어 있다. 이 시안 세트는 도면 내부 표기를 따라 1층과 2층으로 정리했다.

## 2층·5층 승강기 정정

초기 2층·5층 시안은 승강기와 계단·샤프트 기호를 혼동했다. 초기 파일은 비교용으로 보존하며 앱과 발표 자료에는 `v2`를 사용한다.

- 2층: 상단 왼쪽에 잘못 표시된 승강기 2개를 제거했다. 201·202호 인근 코어와 건물 중앙의 두 수직 코어에 승강기를 표시했다.
- 5층: 513·516호 사이의 좁은 샤프트에 잘못 표시된 승강기를 제거했다. 501호 인근 코어와 512·513호 사이, 516·518호 사이 코어에 표시했다.

승강기 아이콘은 공식 평면도 기호를 대조한 시안이다. 실제 운행 여부와 정차층은 현장 조사로 최종 확인한다.
